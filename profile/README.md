## What we're building

Linura is an intent-driven system layer for Linux. Humans and AI agents can describe what a machine should become; Linura keeps the consequences behind a deterministic authority boundary that plans, authorizes, executes, verifies, audits, and reconciles managed change.

The intelligence layer may be probabilistic. **Machine authority is not.**

```text
human / agent intent
        ↓
      propose
        ↓
observe → plan → validate → authorize → prepare
        ↓
execute → verify → commit → audit → reconcile
        ↓
 verified machine state
```

**Agents propose. Linura decides and executes.**

## Open source, before 1.0

Linura is currently experimental and pre-1.0. Supported-platform boundaries, qualification evidence, compatibility claims, release status, governance, and security policy are version-scoped and remain canonical in the [`linura`](https://github.com/linura-org/linura) repository.

This organization profile is intentionally a front door, not a second source of truth.
