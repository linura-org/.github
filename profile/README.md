## One machine model. One authority path.

Linura is an intent-driven, deterministic control and execution layer for Linux, AI agents, containers, and virtual machines. Probabilistic systems may propose what should happen; Linura keeps authority, execution, verification, and durable machine state behind explicit system boundaries.

```text
request / intent
      ↓
observe → plan → validate → authorize → prepare
      ↓
execute → verify → commit → audit → reconcile
```

**Agents propose. Linura decides and executes.**

## Project boundary

Linura is currently pre-1.0 and experimental. Release claims, supported platform boundaries, qualification evidence, and compatibility guarantees are version-scoped and live in the canonical [`linura`](https://github.com/linura-org/linura) repository.

The organization profile is intentionally concise. Architecture, governance, security policy, contribution rules, and support policy remain canonical in the project repository so there is one source of truth.
